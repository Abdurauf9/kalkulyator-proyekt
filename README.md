# 🧮 Kalkulyator

HTML, CSS va vanilla JavaScript'da yozilgan oddiy kalkulyator. Git va GitHub'ni o'rganish uchun namuna proyekt.

## Imkoniyatlar

- Qo'shish, ayirish, ko'paytirish, bo'lish
- Foiz (`%`) hisoblash
- `AC` (tozalash) va `⌫` (oxirgi raqamni o'chirish)
- Nolga bo'lishda `Xatolik` xabari
- Klaviatura orqali boshqarish (raqamlar, `+ - * /`, `Enter`, `Backspace`, `Esc`)
- Katta sonlarni ajratib ko'rsatish: `1 000 000`

## Ishga tushirish

Hech qanday o'rnatish shart emas — `index.html` faylni brauzerda oching.

```bash
start index.html
```

## Fayllar tuzilishi

```
kalkulyator-proyekt/
├── index.html   # sahifa tuzilishi
├── style.css    # ko'rinish
├── script.js    # kalkulyator mantiqi
└── README.md
```
